Browser session, not a persistent seed

DistroSea is for testing Linux distributions in temporary browser sessions. It is not a user-owned, always-on server. Session lifetime, persistence, and inbound networking are not guaranteed, so don’t advertise it as a stable P2P seed or production node. A public seed needs an always-on host with a reachable public IP and TCP 9433.

The current node software serves the EXCAL fork network; it is not a Bitcoin mainnet node. Its production setup and monitoring notes are in the node deployment guide.

Publish this static site on IPFS

On an online machine with Kubo installed and a running IPFS daemon, from the repository root run:

ipfs add -Qr --pin=true --cid-version=1 docs

Open the printed CID at https://<CID>.ipfs.dweb.link/. This serves the static site only; keep the directory pinned on an always-on IPFS node or a pinning service. The live node and network status still require an online EXCAL node.

Deploy a persistent P2P seed

For public P2P service, deploy the node on an always-on Ubuntu VM and keep JSON-RPC and Prometheus private. See the deployment guide for setup and firewall details.
