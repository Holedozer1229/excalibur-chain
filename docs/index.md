# Excalibur-Chain

**SphinxOS Nexus — Grand Unified Quantum Blockchain Organism**

Excalibur-Chain is a living blockchain with ~25,600 blocks, post-quantum cryptography, conscious consensus, and self-organizing infrastructure.

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run the Nexus demo
python demo_nexus.py

# Use the Holo-wallet
python holo_wallet.py generate
python holo_wallet.py balance
python holo_wallet.py status
```
