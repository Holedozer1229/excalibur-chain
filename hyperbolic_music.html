How It Works

This composition maps the spectrum of the Laplacian on a random hyperbolic surface to musical frequencies. Each eigenvalue λₖ = sₖ(1-sₖ) becomes a note, with the spectral gap λ₁ ≥ 3/16 ensuring harmonic separation.

λₖ = sₖ(1-sₖ) → f = 440 × 2^((λₖ × 12)/12) Hz

The Möbius function μ(n) provides counterpoint: positive values create harmonic reinforcement, negative values create dissonant tension, and zero values create rests — mirroring the square-free condition in number theory.

μ(n) > 0 → Major intervals | μ(n) < 0 → Minor intervals | μ(n) = 0 → Rest
